## 前置条件
- 测试账号 demo / secret 已注册
- 应用服务已启动

## 操作步骤
1. 打开 https://app.example.com/login
2. 在"用户名"输入框输入 demo
3. 在"密码"输入框输入 secret
4. 点击"登录"按钮
5. 等待页面跳转到首页

## 期望结果
- 页面 URL 变为 https://app.example.com/
- 页面顶部显示"欢迎回来，demo"
