## 前置条件
- 可访问 https://www.wlw-staging.de（staging）
- 测试账号信息：账号：anytherm.redaktion@gmail.com、密码：Qwer123@456!
- conversationId、organizationId 对当前账号有效（见团队测试数据说明）

## 操作步骤
1. 以 headed 模式打开 https://www.wlw-staging.de/de/registration?return_to=/
2. 如出现 Cookie 同意条，点击「Alle akzeptieren」
3. 输入邮箱并点击「Weiter」，再输入密码并点击「Einloggen」，完成登录
4. 登录成功后保存浏览器登录态到工程根目录 login-state.json
5. 新建浏览器会话 api，加载 login-state.json 后打开 https://www.wlw-staging.de/en/conversations
6. 在 api 会话中向 conversations messages 接口发起 GET（完整 URL 含 conversationId、organizationId、pageSize=40、page=0、reverseOrder=true），并记录响应

## 期望结果
- 登录后页面不再停留在 login/registration 流程页
- login-state.json 已成功生成
- GET 返回 2xx
- 响应体非空且为合法 JSON
