## 前置条件
- TodoMVC 示例应用和百度网站可访问
- 浏览器能够访问互联网

## 操作步骤
1. 打开 https://demo.playwright.dev/todomvc
2. 在待办输入框中输入 "Read Playwright guide" 并回车
3. 在待办输入框中输入 "Practice UI testing" 并回车
4. 勾选列表中的第一条待办 "Read Playwright guide"
5. 确认列表中有两条待办，且 "Read Playwright guide" 已完成
6. 在当前浏览器会话中打开 https://www.baidu.com
7. 在百度搜索框中输入 "Playwright 自动化测试" 并提交搜索

## 期望结果
- TodoMVC 中出现两条待办，文本分别为 "Read Playwright guide" 和 "Practice UI testing"
- "Read Playwright guide" 处于已完成状态（带删除线）
- 百度搜索页显示搜索词 "Playwright 自动化测试"
- 百度搜索页显示与该搜索词相关的搜索结果
