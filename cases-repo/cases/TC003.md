## 前置条件
- 前置用例 TC001 已执行过，或测试账号 demo / secret 可用

## 操作步骤
1. 打开 https://app.example.com/login，用 demo / secret 完成登录
2. 登录成功后执行 state-save，把登录态保存到 tc003-state.json
3. 新开一个名为 tc003-api 的会话，打开 https://app.example.com 并加载 tc003-state.json
4. 在 tc003-api 会话中，通过 page.request 向 https://api.example.com/data 发送 POST 请求，JSON 体为 {"foo": "bar"}
5. 记录返回的响应状态码和响应体

## 期望结果
- POST 请求返回 2xx 状态码（服务端认可了携带的登录态）
- 响应体为合法 JSON，且能打印出来
